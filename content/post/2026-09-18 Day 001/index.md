I just installed Hugo for the first time in my new system (Fedora)!

```bash
sudo dnf install hugo
```

## Why Hugo?

- **Static site** — no database, no server-side code
- **Fast** — built in Go, renders pages in milliseconds
- **Free hosting** — deploy to GitHub Pages for free
- **Markdown-first** — write in Obsidian, publish anywhere
- **Themes** — 300+ themes, minimal configuration

## What I'm Using

| Hugo | Static site generator |
